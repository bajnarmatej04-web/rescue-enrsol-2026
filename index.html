Rescue

Aplikace se nespustila / The app did not start

Nejčastější příčina: soubor index.html byl otevřen přímo ze ZIP archivu nebo bez ostatních souborů. Klikněte na stažený ZIP pravým tlačítkem, zvolte Extrahovat vše a pak otevřete index.html v rozbalené složce. Vedle něj musí být složky css, js, lang a data.

Most common cause: index.html was opened directly from the ZIP file or without the other files. Right-click the downloaded ZIP, choose Extract All, then open index.html in the extracted folder. The folders css, js, lang and data must be next to it.
